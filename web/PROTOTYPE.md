## 技術栈

- **框架**: Next.js 14
- **UI**: React + Tailwind CSS
- **狀態管理**: useState + useEffect
- **圖標**: SVG (Lucide icons)
- **部署**: Vercel / any Node.js host

## 執行方式

```bash
cd web
npm install
npm run dev
```

打開 http://localhost:3000 即可預覽。

## 螢幕截圖

運行後你將看到：
1. **首頁** - 搜尋框 + 地區標籤 + 店家卡片列表
2. **點擊卡片** - 彈出店家詳情 Modal
3. **WhatsApp 按鈕** - 一鍵跳轉預約
4. **收藏按鈕** - 添加/移除收藏
5. **我的收藏** - 查看已收藏店家
